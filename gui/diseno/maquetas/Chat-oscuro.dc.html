Selection sort en C++

Dame un selection sort en C++ y explícamelo corto.
Pensamiento · 52 palabras

Piden un selection sort en C++ y una explicación corta. Lo más claro es una función que reciba un std::vector<int> por referencia. Dos ciclos: el de afuera marca dónde empieza la parte sin ordenar y el de adentro busca el mínimo; luego std::swap. La explicación en tres viñetas, una por pieza.

Busca el elemento más chico de lo que falta por ordenar y lo pone al frente. Repite hasta terminar.

cpp 
void selection_sort(std::vector<int>& v) {
    for (size_t i = 0; i + 1 < v.size(); ++i) {
        size_t min = i;
        for (size_t j = i + 1; j < v.size(); ++j)
            if (v[j] < v[min]) min = j;
        std::swap(v[i], v[min]);
    }
}
  • El ciclo de afuera marca dónde empieza la parte sin ordenar.
  • El de adentro busca el mínimo de esa parte.
  • std::swap lo pone en su lugar.
¿Y cuál es su complejidad?
Pensamiento · 41 palabras

Preguntan la complejidad. Selection sort siempre recorre lo que falta para hallar el mínimo, sin importar el orden inicial: n−1 + n−2 + … + 1 comparaciones, o sea n(n−1)/2. Es O(n²) en el mejor, el promedio y el peor caso.

Es O(n²) en todos los casos: siempre recorre lo que falta para encontrar el mínimo, aunque el arreglo ya venga ordenado
